# Education UI Template Collection

Four distinct education-sector web apps:

1. Virtual Classroom - lesson progress and completion tracking.
2. Quiz Arena - interactive quiz with scoring and restart.
3. Flashcard Studio - create, flip and delete flashcards.
4. Study Planner - add, complete and delete study tasks.

## Run
Open `index.html` in a browser. No server or API key is required.

Data for progress, flashcards and tasks is stored in the browser with localStorage.
